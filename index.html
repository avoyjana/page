Gaussian Function

$$f(x) = e^{-x^2}$$

Two important uses of Gaussian function are:

Error function is defined as $$\mathrm{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{-z^2} \, dz$$

The Dirac delta function can be represented as $$\delta(x) = \lim_{\epsilon \to 0} \eta_\epsilon(x), \quad \eta_\epsilon(x) = \frac{1}{\sqrt{2\pi \epsilon}} e^{-x^2 / 2\epsilon}$$ where $$\eta_\epsilon(x)$$ is heat/ diffusion kernel.

Some integrals involved Gaussian are

Euler-Poisson integral: $$\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$$

Normal Distribution

$$f(x) = \frac{1}{\sqrt{2\pi \sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

$$\langle x \rangle = \mu, \quad \langle (x - \langle x \rangle)^2 \rangle = \sigma^2$$

Fourier Transform

$$\tilde{f}(k) = \int_{-\infty}^{\infty} e^{-ikx} f(x) dx$$

$$= \frac{1}{\sqrt{2\pi \sigma^2}} \int_{-\infty}^{\infty} e^{-\frac{(x-\mu)^2}{2\sigma^2}} e^{-ikx} dx$$

Let \( x - \mu = t \):

$$= e^{-ik\mu} \int_{-\infty}^{\infty} e^{-\frac{t^2}{2\sigma^2}} e^{-ikt} dt$$

$$= e^{-ik\mu} \sqrt{2\pi \sigma^2} e^{-\frac{\sigma^2 k^2}{2}}$$

Moment Generating Function

$$M(t) = E[e^{tx}] = \int_{-\infty}^{\infty} e^{tx} f(x) dx$$

$$M(t) = e^{\mu t + \frac{\sigma^2 t^2}{2}}$$

$$E[x^n] = \left.\frac{d^n M}{dt^n}\right|_{t=0}$$

$$E[x] = \mu, \quad E[x^2] = \mu^2 + \sigma^2$$

Gaussian Wave Packet

A wave packet is a superposition of plane waves:

$$\Psi(x,0) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} \phi(k) e^{ikx} dk$$

Choose:

$$\phi(k) = \phi_0 e^{-\frac{(k-k_0)^2}{4\sigma_k^2}} e^{i(k_0-k)x_0}$$

Normalization:

$$\int |\phi(k)|^2 dk = 1$$

$$\phi_0 = \left(\frac{1}{2\pi \sigma_k^2}\right)^{1/4}$$

$$\Psi(x,0) = A_0 e^{-\sigma_k^2 (x-x_0)^2} e^{ik_0 x}$$

$$A_0 = \left(\frac{2\sigma_k^2}{\pi}\right)^{1/4}$$

Uncertainty Relation

$$p = \hbar k$$

$$\sigma_x \sigma_p = \frac{\hbar}{2}$$

Expectation Values

$$\langle p \rangle = -i\hbar \int \Psi^* \frac{\partial \Psi}{\partial x} dx$$

$$\langle p \rangle = \hbar k_0$$

$$\langle p^2 \rangle = \hbar^2 k_0^2 + \frac{\hbar^2}{4\sigma_x^2}$$

$$(\Delta x)^2 (\Delta p)^2 = \frac{\hbar^2}{4}$$

Time Evolution

$$H = \frac{p^2}{2m} = \frac{\hbar^2 k^2}{2m}$$

$$\Psi(x,t) = e^{-\frac{i}{\hbar}Ht} \Psi(x,0)$$

$$\Psi(x,t) = \frac{1}{\sqrt{2\pi}} \int \phi(k) e^{ikx} e^{-iE_k t/\hbar} dk$$

After integration:

$$\Psi(x,t) = \left(\frac{1}{2\pi \sigma_x^2}\right)^{1/4} \frac{\sigma_x}{\sigma_x(t)} e^{-\frac{(x-x_0)^2}{4\sigma_x^2(t)}} e^{ik_0 x}$$

$$\sigma_x^2(t) = \sigma_x^2 + \frac{i\hbar t}{2m}$$

Probability Density

$$P(x,t) = |\Psi(x,t)|^2$$

$$P(x,t) = \frac{1}{\sqrt{2\pi \sigma_x^2(t)}} e^{-\frac{(x-x_0)^2}{2|\sigma_x(t)|^2}}$$
